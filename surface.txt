## rsxtk --help
Usage: rsxtk <COMMAND>

Commands:
  run       🏃 Run a WASI app or script
  mod       🧩 Execute functions from a library
  csrun     🚀 Native execution via 'cargo -Z script'
  build     🔨 Build a universal .wasm or .wat file
  convert   🔄 Convert between .wasm and .wat
  init      ✨ Init a new script template
  initmod   📦 Init a new library module template
  resource  📂 Create 'rsc' folder for local files
  bench     ⏱️ Benchmark execution speed
  add       ➕ Add a dependency (Auto-injects manifest if missing)
  remove    ➖ Remove a dependency
  list      📦 List script dependencies
  fmt       ✨ Format Rust code (Preflight check for manifests)
  optimize  🧹 Optimize WASM via Walrus
  clean     🗑️ Wipe the .tk build cache
  info      📝 View WASM metadata (wasmtk style)
  help      Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
